# آریاپک | نمونه وب‌سایت شرکت کارتن‌سازی

وب‌سایت فارسی و واکنش‌گرا برای معرفی یک شرکت تولیدکننده کارتن و جعبه بسته‌بندی.

## امکانات
- صفحه اصلی، معرفی برند و آمار نمایشی
- معرفی کارتن سه‌لایه و پنج‌لایه، جعبه لمینتی و دایکاتی
- مگامنوی دسکتاپ با دسته‌بندی محصولات، تصویر شاخص و دسترسی سریع
- منوی اختصاصی موبایل با زیرمنوی بازشونده
- فرآیند تولید، گالری، پرسش‌های متداول و فرم استعلام
- فوتر چندستونه با معرفی برند، لینک‌های سریع، محصولات و راه‌های ارتباطی
- favicon اختصاصی و چیدمان واکنش‌گرا

## انتشار در GitHub Pages
در تنظیمات مخزن، بخش **Settings → Pages** را باز کنید. منبع را روی **Deploy from a branch** قرار دهید و شاخه `main` و پوشه `/(root)` را انتخاب کنید.

## نکته‌های پیش از استفاده واقعی
نام برند، شماره تلفن، نشانی، ایمیل، آمار و تصاویر باید با اطلاعات واقعی شرکت جایگزین شوند. تصاویر فعلی از Unsplash بارگذاری می‌شوند و صرفاً نمایشی‌اند. فرم استعلام هنوز به سرویس ارسال اطلاعات یا CRM متصل نیست.
